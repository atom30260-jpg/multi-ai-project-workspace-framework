# 项目登记与进门门禁

## 项目登记表模板

```yaml
project_id: <唯一ID>
project_name: <项目名称>
workspace_root: <项目工作台绝对路径>
obsidian_vault: <项目Obsidian绝对路径>
git_root: <若有则填写，否则 none>
git_remote: <若有则填写，否则 none>
mainline: <主线名称>
memory_location: <项目记忆位置>
candidate_pool: <项目候选池位置>
automation_location: <项目自动化位置>
allowed_read: <允许读取范围>
allowed_write: <允许写入范围>
status: registered|partial|blocked|verified
```

## 进门顺序

1. 判断当前对话属于哪个项目。
2. 读取全局核心门禁和用户通用偏好。
3. 读取该项目身份卡。
4. 读取当前任务胶囊和相关模块入口。
5. 仅按影响范围读取项目页面和证据。

无法判断项目归属、路径或写入范围时，状态为 `blocked`，不猜测。

## 范围确认

- `scope: project`：只能写入当前项目。
- `scope: global-candidate`：等待用户确认，不得直接写入全局。
- `scope: global`：用户明确确认后才可同步全局。
