# Multi-AI Project Workspace & Knowledge Base Framework

中文名：多 AI 项目工作台与知识库隔离框架

GitHub 建议仓库名：`multi-ai-project-workspace-framework`

一句话说明：一个本地优先的多 AI 项目管理框架，用于隔离工作台、Obsidian 知识库、记忆、权限和断网交接。

**版本**：v1.0
**日期**：2026-08-29
**用途**：供其他 AI 或新的个人工作台复制“项目隔离、知识分层、任务治理、记忆恢复”的管理思路。

本模板已去除个人姓名、真实项目名称、真实路径、业务数据、账号、Token、Cookie、私钥、证书和其他敏感值。所有尖括号字段都必须由使用者替换。

## 一键初始化

执行 `bootstrap-framework-only.sh <新机框架根目录>`，只重建空白管理框架，不恢复任何旧项目或旧数据。

## 核心思想

```text
全局控制层
  -> 判断当前项目
  -> 读取项目身份卡
  -> 进入项目自己的工作台与 Obsidian
  -> 按任务影响范围读取
  -> 项目内完成任务、记录和回写
  -> 主线审核后闭环
```

全局只保存真正通用的门禁、用户习惯和恢复框架；项目事实、项目记忆、项目自动化和项目 AI 适配内容永远留在项目自己的空间。
