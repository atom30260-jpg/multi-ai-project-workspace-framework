# 重要事件回写闭环

## 触发事件

- 新建任务或切换项目。
- 修改规则、架构、Canvas、数据、接口或实体关系。
- 模块版本迭代。
- 分支完成、审核、合并、提交或推送。
- 网站、服务器包或阶段成果交付。
- 建立不属于当前主线的新模块。
- 用户明确要求补充知识库。

## 处理流程

```text
识别事件
→ 判定项目
→ 生成影响范围清单
→ 只读相关模块和证据
→ 写入项目知识或候选池
→ 主线审核
→ 回读验收
→ 记录版本、证据和回退边界
```

## 影响清单

- 决策层级树。
- 模块架构和 Canvas。
- 数据、接口和实体关系。
- 新链路、新方法和操作流程。
- Git 或本地版本证据。
- 网站/服务器包交付证据。
- 任务、分支和审核记录。
- 项目记忆、候选池、索引和反向链接。

无影响的模块不读取；普通对话不触发全库扫描。
