# 新项目建立清单

- [ ] 生成唯一 `project_id`。
- [ ] 创建独立工作台根目录。
- [ ] 创建必要/非必要分层。
- [ ] 创建独立 Obsidian Vault。
- [ ] 创建主页、项目身份卡、总览和索引。
- [ ] 建立主线、需求规划台和治理规则台。
- [ ] 建立任务、分支、审核和交付记录。
- [ ] 建立项目记忆和项目候选池。
- [ ] 建立每个 AI 自己的适配区。
- [ ] 登记 Git 或明确记录本项目不使用 Git。
- [ ] 写入全局门禁完整副本。
- [ ] 完成一次最小恢复演练。
- [ ] 检查是否误读、误写其他项目。

## 新项目禁止继承

不得自动继承其他项目的业务知识、项目记忆、Git、分支、自动化、对话历史或 AI 私有适配区。
