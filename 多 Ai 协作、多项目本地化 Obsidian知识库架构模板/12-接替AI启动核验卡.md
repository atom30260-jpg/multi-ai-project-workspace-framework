# 接替 AI 启动核验卡

严格从上到下执行，不得跳步：

- [ ] 我知道自己是哪一个 AI，且只读取自己的本体规则。
- [ ] 已确认项目 ID 和项目名称。
- [ ] 已确认本地工作台真实路径。
- [ ] 已确认项目 Obsidian 真实路径。
- [ ] 已读取项目身份卡和治理规则。
- [ ] 已找到最新且唯一的续作 MD。
- [ ] 已核对续作 MD 的日期、任务 ID 和来源 AI。
- [ ] 已实时核验相关文件仍存在。
- [ ] 已核验版本、哈希或修改时间是否漂移。
- [ ] 已检查是否存在其他 AI 正在写同一批文件。
- [ ] 已明确允许写入和禁止操作范围。
- [ ] 已确认唯一下一步。

任何一项无法确认：停止修改，状态写为 `blocked`，向用户报告具体缺口。
